# ARMY ANTS（アーミーアンツ、仮題）

アリの群れを左右に動かして数字のゲートで仲間を増やし、実在のアリの能力で「変異」しながら
敵の虫と巣を倒す、スマホ向けのブラウザゲーム（Tanuki Box・開発中）。

- 指示書：[docs/instructions.md](docs/instructions.md)
- ゲーム：https://tanukibox.github.io/army-ants/
- 見た目の試作（フェーズ1）：https://tanukibox.github.io/army-ants/prototype/

## 遊び方（作り直し中：参考動画に寄せた版）

いまは作り直しの途中です（エリア1の4ステージが遊べます）。

- 画面のどこでも左右にドラッグすると、群れが動きます（PC はマウスのドラッグか ← → キー）。前進と射撃は自動です。
- アリはそれぞれ前へ撃ちます。弾1発で、的の数字がちょうど1減ります。弾は少し先までしか届きません。
- **卵の山**：上にアリが乗っています。撃ち割ると、そのアリが走ってきて仲間になります（+1）。
- **変異の繭**：撃ち割ると、上に浮かぶアリの能力に変わります（同じ種類なら Lv+1）。
- **捕らわれた兵隊アリ**：クモの糸を撃って助けると、群れの真ん中で強い針を撃ち続けます。
- **兵隊シロアリ**：体力バー付きで列になって迫り、群れに着くと噛みついてきます。先に撃ち倒します。
- **働きシロアリの大群**：1発で1匹。触れると1匹ずつ相殺。
- **＋の道**・**−の看板**（撃つと1ずつ上がる）・**赤い円**（ミイデラゴミムシのガス。逃げる）。
- 上の **☠ 残り** はこのステージのシロアリの数。巣に着くと守りが出てきます。0 にすると巣が落ちてクリア。
- **警報フェロモン**：倒すと画面下のゲージがたまり、満タンで5秒間、群れが大暴れします。
- **法則カード**：ステージの合間に3枚から1枚を選びます。

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `index.html` | ゲーム本体 |
| `js/game/` | ゲームの流れ（main）・1ステージ（lane）・ステージの作り方（course）・効果音・日英の文字・セーブ。runner / boss / stages / siege は作り直し前のもの（R2 でボスを移したあと片づける） |
| `js/game/config.js` | **数値をまとめた設定ファイル**（敵の強さ、ゲートの値、繭の耐久、蜜、強化の値段など） |
| `js/game/cards.js` | 法則カードの一覧（名前・説明・効果） |
| `js/game/meta.js` | 女王の部屋・侵攻度・今日のコース・蜜 |
| `js/core/` | 画面・群れ・地面・エフェクト・操作の部品（試作とゲームで共通） |
| `prototype/` | フェーズ1の試作ページ（変異の種類・Lv・匹数・拡大を切り替えて見比べる） |
| `assets/sprites/` | ゲームで使うドット絵（`art/build.py` が自動で作る。手で描きかえない） |
| `art/` | Blender の3Dモデル → ドット絵の仕組み。作り方は [art/README.md](art/README.md) |
| `art/blend/` | Blender で開ける見本ファイル（アリ・敵・ボス・地面） |
| `vendor/` | 描画ライブラリ PixiJS 8.22.0（MIT ライセンス、`PIXI-LICENSE.txt`） |

## PC で動かす

WebGL で画像を読むため、ファイルをダブルクリックでは開けません。このフォルダで次を実行し、
ブラウザで http://localhost:8123/ を開きます（止めるときは Ctrl+C）。

```
python -m http.server 8123
```
