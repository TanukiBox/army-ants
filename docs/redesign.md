# ARMY ANTS 作り直しの仕様案（v2・歩夢の確認待ち）

参考：歩夢が送った動画2本（城を攻めるシューティングと、兵士の群れが大群を撃つ広告）と、「桜井政博のゲーム作るには」のまとめ（ゲーム性1・企画・ゲーム設計1）。

## 0. ひとことで

アリの群れを左右に動かし、迫ってくるシロアリの大群を撃ちまくる縦画面シューティング。
卵を撃ち割って仲間を増やし、繭を撃ち割って実在のアリの能力に変異しながら、ステージの奥にある敵の巣を落とす。

* 群れの数は「体力」であり「火力」。1匹ずつ全部を画面に描き、多いほど弾が増える（最大300匹）
* 数字は小さく保つ（数十〜300匹）。100万匹のような、画面が変わらない数にはしない

## 1. 参考にしたもの

動画2本から取り入れること：

* 撃つ相手に数字が付いていて、撃つと目の前で減っていく（樽・箱・看板）
* ごほうびが、撃つ相手の上に見えている（樽の上の兵士、箱の上の銃）。割ると、それが群れに飛び込んでくる
* 敵は「大群」で迫ってくる。撃ちまくって、まとめて消えていくのが気持ちいい
* 武器が変わると、弾の見た目がはっきり変わる（矢 → 青く光る弾）
* 群れが立つ位置で「何を撃つか」と「何に当たるか」が決まる（＋の列に寄る・箱を撃つ・大群を撃つ）
* 赤い円の予告をよける
* 上に「敵の残り」の数字があり、ゴールがはっきりしている

まねで終わらせないための、ARMY ANTS だけの魅力（C-22）：

* 実在のアリの武器：毒が大群の中で広がる、毒針が列を貫く、自爆アリが大群の中で爆ぜる、顎で近くの敵をはじき飛ばす
* 暗い地面の上を、光る群れが進むドット絵
* ローグライト：法則カードの組み合わせで、毎回ちがう群れになる

## 2. いまの作りでうまくいかなかったこと

* ×ゲートで数が増えすぎて、敵が相手にならない（自動操作のテストで、最後に約99万匹）
* ボスの攻撃が「群れの〇%を減らす」なので、何度当たっても0匹にならない
* 攻城は、巣の固さをこちらの数に合わせているので、どれだけ集めても半分以上を失う
* 約900匹より多い分は数字が増えるだけで、画面が変わらない
* 大群を倒す・巣が崩れる・ボスが倒れる、といった「決めの場面」の演出が弱い

## 3. 新しい遊び方

画面（縦）：

* 下：自分の群れ。前へ進み続け、指で左右に動く（今と同じ操作。画面のどこを触ってもよい）
* 真ん中：コース。卵・繭・シロアリの大群・看板などが、奥から近づいてくる
* 上：ステージのゴール（敵の巣までの道のり。巣が見えたら巣の耐久）

射撃：

* 群れのアリが、それぞれ真っ直ぐ前へ撃つ（自動）。群れが大きいほど弾が多く、横にも広く当たる
* 群れの幅は「当てられる広さ」であり「当たってしまう広さ」でもある（B-1：砲台の横幅）。
  10匹なら細く、300匹なら道の3分の1くらい
* 弾は石で止まる

## 4. コースに出てくるもの

| もの | 撃つと | 群れが触れると |
| --- | --- | --- |
| 卵の山（耐久の数字。上に「+8」とさなぎが見える） | 割れて、生まれたアリが走って群れに加わる | — |
| 変異の繭（上に光る輪とアリの姿・名前） | 変異する（武器が変わる、Lv が上がる） | — |
| シロアリの大群（20〜400匹） | 1発で1匹ずつ倒れる | 1匹ごとに1匹ずつ相殺（群れが減る） |
| 兵隊シロアリ（大きい。体力バー付き） | 何発も当てて倒す | 赤い線の予告のあと突進してきて、まとめて倒される |
| ミイデラゴミムシ | 何発も当てて倒す | 赤い円の予告のあと、熱いガスを吹く |
| ＋の道（＋1が何枚も並んだ列） | — | 1枚通るごとに1匹増える。たいてい大群や卵と反対側にある |
| −の看板（−20 など） | 撃つと数字が上がる（−20 → +5） | 触れるとその数だけ減る（＋になっていれば増える） |
| 金の×2ゲート（たまに） | — | 群れが2倍。めったに出ないごほうび（最大300匹まで） |
| 石・水たまり | 弾を止める | 群れが流れてよける／入ったアリがおぼれる |

300匹を超えて増えた分は、蜜に変わる。

## 5. ステージの流れ

1ステージは約45〜60秒。

1. 少ない群れでスタート（例：10匹。女王の部屋の強化で増える）。最初の5秒以内に、卵と小さな大群が出る（C-2）
2. 道中：卵で増やす、繭で変異する、大群を撃ちまくる、をくり返す。危ないもの（大群・予告）とごほうび（卵・繭）を近くに並べ、どちらを撃つかを選ばせる
3. ゴール：奥に敵の巣が現れて止まる。巣はシロアリを出しながら耐える。撃ち落とせばクリア
4. 巣の耐久は、ステージごとに決まった値（こちらの数に合わせない）。たくさん集めた群れほど、一瞬で落とせる。
   残った匹数とかかった時間で、蜜のボーナスと星（★1〜3）がもらえる
5. 群れが0匹になったら失敗。ランは終わる。結果画面から1タップで、すぐやり直せる（B-14）

1-1 の例（約50秒）：

* 0秒：10匹でスタート。左に卵（耐久12、+8）、右からシロアリ15匹
* 8秒：真ん中にヒアリの繭（耐久40）。その後ろからシロアリ30匹
* 15秒：右に＋1の道（6枚）、左に卵
* 22秒：シロアリの大群80匹（ギュッ）。ヒアリの毒が大群の中で広がり、まとめて溶ける（パッ）
* 32秒：−10の看板。撃って上げるか、よけるか
* 38秒：ミイデラゴミムシ（赤い円をよける）
* 45秒：敵の巣（耐久300）

## 6. 変異（武器は一長一短に尖らせる）

* ふつう（蟻酸）：真っ直ぐの弾
* アギトアリ：弾の代わりに、近くの敵を顎でまとめてはじき飛ばす。近いほど強い。大群に自分から寄る勇気がいる（B-16）
* ヒアリ：毒の弾。毒は大群の中で隣へ広がる。大群には最強、ボスには弱い
* サシハリアリ：毒針が一列を貫く。弾は少なく遅いが、列ごとまとめて倒せて、ボスに強い
* 自爆アリ：群れから1匹ずつ飛び出し、大群の中で爆発する。範囲は最大だが、使うたびに群れが減る
* 甲殻装甲（防具）：ぶつかったとき・攻撃を受けたときに減る数が少なくなる

同じ種類を取ると Lv+1（最大3）。別の種類は持ち替え（Lv はそのまま引きつぐ）。Lv が上がると、弾の見た目が大きく派手になる。

## 7. ボス（各エリアの最後）

* 体力は決まった値。攻撃は「〇匹倒す」という決まった数（%ではない）。よけ損ねると全滅もある
* 体力が減ると攻撃が変わり、速くなる（3段階）
* 攻撃のあとにすきができ、そこに撃ち込むと大ダメージ（攻略法がはっきり分かる、B-25）
  * オオカマキリ：鎌で道の半分を薙ぐ（安全な側へ逃げる）。振り下ろしたあと頭が下がる＝弱点
  * ジョロウグモ：糸で道をふさぎ（弾が止まる）、子グモの大群を降らせる
  * オオスズメバチ：赤い円へ急降下。地面に刺さって動けない間が弱点
  * 女王バチ：上の3体の攻撃を混ぜ、最後は手下を呼びながら針を連射する

## 8. ランの構成

* 1ラン＝3エリア×5ステージ（今と同じ。約15分）
* 各エリア：ふつうのステージ3つ → 「大群の巣」（巣が2つ、大群が多い山場）→ ボス
* ときどき、合間に「蜜の部屋」が入る。敵がいない、卵と蜜だけのごほうびステージ（B-13：ほっとできる場所）
* 法則カード（合間に3枚から1枚）・女王の部屋・侵攻度・今日のコースは残す。カードの中身は、新しい遊びに合わせて作り直す
* 救済（B-24）：同じエリアで2回続けて負けると、次の出撃で「女王の加護」（最初の群れ+10）を選べる

## 9. 気持ちよさの演出とアニメーション

1. 撃ったとき（C-12）：数字が回りながら減る。当たった相手が白く光ってゆれる。火花が出る
2. 大群をなぎ払う（B-2）：1匹ずつ殻が割れて飛ぶ。まとめて倒すと「〇匹撃破！」。大群の最後の1匹で一瞬スローになる
3. 卵が割れる：殻が飛び、生まれたアリが走って群れに加わる。群れが目に見えて大きくなる
4. 変異（B-9・C-11）：繭が割れ、中のアリが光の輪と一緒に群れへ落ちる → 群れ全体に光が走る → その場で弾が変わる。「Lv UP」の文字
5. 巣が落ちる：ひびが入る → 崩れる → 土ぼこりと蜜が噴き出す → 群れが巣に流れ込む
6. ボス撃破：一瞬止まる（ヒットストップ）→ スロー → 大爆発 → 倒れる → 群れが群がる
7. 攻撃を受けたとき：赤く光り、減った数を大きく出す。画面の揺れは大きな攻撃のときだけ
8. ほめる（C-11・C-23）：「全滅！」「無傷！」「★3」。クリア時に、数字が勢いよく数え上がる

新しく作る絵（Blender → ドット絵）：卵の山とさなぎ、兵隊シロアリ、シロアリが割れて死ぬ動き、巣が崩れる段階、子グモ、アリが撃つ・噛むしぐさ

## 11. 残すもの・変えるもの・やめるもの

* 残す：絵の仕組み（Blender → ドット絵）。アリ52種・ボス4体・地面・繭・シロアリ・ゴミムシ・石の絵。
  左右ドラッグの操作。変異（武器4種＋防具）。ボス4体の題材。法則カード・女王の部屋・侵攻度・今日のコース・Xシェア・セーブ・日英
* 変える：ゲートは主役でなくなる（＋の道と−の看板、たまに金の×2）。群れの数は小さく、全部描く（最大300匹）。
  ボスは決まった数を減らす攻撃と3段階
* やめる：×÷ゲートの「撃って育てる」と「かすり取り」。送り込む攻城。じゅうたん状に描く大きな群れ

## 12. 決めてほしいこと

1. 群れの数を、ステージごとにどうするか
   * A（おすすめ）毎ステージ少数（10匹＋強化）から始める。持ち越すのは変異とカード。参考の2本も、毎回少数から始まる
   * B 前のステージの残りを持ち越す（上限300匹）。敵の強さは決まった値
2. ゲートをどこまで残すか
   * A（おすすめ）＋の道と−の看板を残し、×は金のごほうびゲートとしてたまに出す
   * B ゲートはなくし、仲間は卵からだけ増やす
   * C 今の×÷ゲートと、かすり取りも残す
3. ステージの最後
   * A（おすすめ）奥に敵の巣が出てきて、撃って落とす（今の「送り込む攻城」はやめる）
   * B 今の送り込む攻城を残す
