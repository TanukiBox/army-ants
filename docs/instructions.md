# ARMY ANTS 指示書

## 0. ゲームの概要

ARMY ANTS（アーミーアンツ、仮題）は、アリの群れを左右に動かして数字のゲートで仲間を増やし、実在のアリの能力で「変異」しながら敵の虫と巣を倒す、スマホ向けのブラウザゲームです。広告でよく見る「ゲートを通って数を増やすゲーム」を、選び方に腕前と先読みが効く、本当に面白いゲームとして作り直します。

* ジャンル：群れランナー＋攻城＋ローグライト
* 対象：スマホの縦画面が主。PCのブラウザでも遊べる。日本語と英語
* 遊び時間：1周（1ラン）約15分。クリア後の高難度と永続強化を含めて合計30分〜1時間
* 公開先：GitHubのTanukiBox内に作る新しいリポジトリ「army-ants」から公開し、既存サイト https://tanukibox.github.io のトップページからリンクする（Tanuki Box名義）
* 見た目：Blenderで作った3Dモデルを自動でドット絵にしたスプライトを使う。暗いドット絵の上に、光る毒や模様をゲーム側で重ねる
* 最優先は「かっこよさ」：黒〜深紅の甲殻、緑や紫に光る毒、暗い地面の上を光る群れが進む画面にする。かわいい・丸っこい絵柄にはしない
* 題材の芯：アリは実在の武器（顎、毒、毒針、自爆、甲殻）を持つ生き物。作り物の装備ではなく、実在のアリの能力で群れが変異していく

## 1. 進め方のルール

* 最初に、GitHubのTanukiBox（tanukibox.github.io を公開しているアカウント）内に新しいリポジトリ「army-ants」を作る。ゲームのファイル、素材（Blenderのファイルを含む）、この指示書（docs/instructions.md）をすべてそこに保存する
* リポジトリは公開（public）で作る。無料のGitHub Pagesで公開するため
* GitHubへのログインなど準備が必要なときは、歩夢に手順を1つずつ説明する
* 各フェーズが終わるたびに、変更をリポジトリに保存する（コミットしてプッシュ）
* この指示書はWBS方式で書いている。成果物ごとに分け、各フェーズに完了の定義を付けた。書いてあるものは全部作り（100%ルール）、書いていない機能は追加しない
* 作業はフェーズ1〜4の順に進める。各フェーズの最後で必ず手を止め、歩夢に確認を頼む。OKが出るまで次のフェーズに進まない
* 歩夢はプログラミング未経験。確認を頼むときは「どのファイルを開くか／どこを押すか／何が見えれば正しいか」を1つずつ書く
* 指示書と食い違う判断や、決まっていない点が出たら、勝手に決めずに選択肢を2〜3個出して質問する
* 数値（敵の強さ、ゲートの値、繭の耐久など）は1つの設定ファイルにまとめ、あとで調整しやすくする

## 2. 共通土台と技術条件

* 片手操作：縦画面で、親指1本ですべて遊べる。PCではマウスのドラッグと、キーボードの左右キーでも操作できる
* 日英の自動切り替え：ブラウザの言語が日本語なら日本語、それ以外は英語で表示する。設定画面で手動でも切り替えられる
* セーブ：永続強化、解放済みの変異とカード、最高記録、設定をブラウザ内に自動保存する。設定画面にデータ消去ボタンを置く
* Xシェア：結果画面に「Xでシェア」ボタンを置く。文面は日英それぞれ用意し、最大匹数・到達エリア・今日のコースの記録・ゲームのURLを入れる
* 技術：1つのWebページとして動き、サーバーは使わない。描画はWebGL（PixiJSなどのライブラリを使ってよい）。素材はすべてリポジトリ内に置く
* 絵の作り方：アリ・敵・ボス・背景の部品は、Blenderで3Dモデルを作り、決まった角度から書き出してドット絵に変換する。Oh!Edo Taco Tuesday!!で使った「Blenderの3Dモデルを自動でドット絵にする仕組み」があれば流用する（場所が分からなければ歩夢に聞く）
* ドット絵の表示：拡大は整数倍で、ぼかさない表示（最近傍補間）にしてドットをくっきり保つ。光はゲーム側の加算合成で重ね、ドット絵そのものはにじませない
* Blenderの動かし方：コマンドで裏で動かす方式にし、Blenderの画面は開かない。作業はこのリポジトリのフォルダ内だけで行う（別のゲームの作業で同時にBlenderを使うことがあるため）
* 性能：中くらいの性能のスマホで、群れ300匹を表示してもなめらかに動く（目安60fps、30fpsは下回らない）
* 音：効果音は必須（コードで生成してよい）。BGMは任意

## 3. フェーズ1：見た目の試作（ここで一度止まる）

このフェーズの目的は、ゲームを作り込む前に「アリの変異でかっこよく見えるか」を確かめること。ゲームのルールはまだ作らない。

1. 通常のアリ（3Dモデル）
   * Blenderで、黒〜深紅の甲殻に光沢があるアリを作る。脚と触角が動く歩行アニメーションを付ける
2. 変異の差分（武器4種＋防具1種、それぞれLv1〜3）
   * 3Dモデルの部品を付け替えて作る
   * アギトアリ（顎型）：Lvが上がるほど顎が長く鋭くなる
   * ヒアリ（毒弾型）：腹部が赤く光り、緑に光る毒弾を撃つ
   * サシハリアリ（毒針型）：大きな毒針に紫の光
   * 自爆アリ（爆発型）：腹部が膨らみ、黄色く脈打つ
   * 甲殻装甲（防具）：外骨格が厚くなり、Lv3で金属のような光沢と光る模様が出る
   * 全種共通：Lvごとに体が少し大きくなり、光る模様が増える
3. ドット絵への書き出し
   * 視点は斜め上からの見下ろし。向きは8方向、歩行は8コマ程度
   * 大きさの目安：アリ1匹は16〜24ピクセル、ボスは128〜256ピクセル
   * 色数をしぼった暗めのパレットにし、明るい色は光る部分だけに使う
   * 光る部分（毒、模様、目）は「発光用」の画像を別に書き出し、ゲーム側で光らせられるようにする
4. 群れの表示
   * 300匹がまとまって動き、指の動きに少し遅れて流れるようについてくる
   * 300匹を超える数は、群れの大きさと密度、頭上の数字で表す
5. 発光と背景
   * 暗い地面（土や落ち葉）もドット絵で作る
   * 発光用の画像を加算合成で重ね、毒と模様が光って見えるようにする（ブルームは控えめ）
   * 攻撃エフェクトを1種類ずつ作る（顎で弾く、毒弾、毒針、爆発）

完了の定義：スマホで試作ページを開き、ボタンで「変異の種類」「Lv」「匹数（1／50／300／1万）」を切り替えて見比べられる。拡大してもドット絵がぼやけない。試作はリポジトリに保存されている。スマホで開く方法はClaude Codeが1つずつ説明する。歩夢が見た目にOKを出したらフェーズ2へ進む。

## 4. フェーズ2：ゲーム本体

1ステージは「前半：走って仲間を集める（30〜60秒）」→「後半：巣から援軍を送り込んで敵の巣を落とす」の2段構成にする。

1. 操作
   * 指を置いた位置からの相対ドラッグで、群れが左右に動く。画面のどこを触ってもよい
   * 群れは自動で前進し、射撃も自動。弾は群れの位置から真っ直ぐ前へ飛ぶ
2. ゲートの規則（このゲームの核）
   * ＋と−のゲートは、1匹でも触れたら全額が加算・減算される
   * ×と÷のゲートは、通過した匹数にだけ効く
   * 群れは横に広がるので、端だけを＋に触れさせ、本体は×に通す「かすり取り」ができる。最初のステージで自然に気づける配置にする
   * 並び順で結果が変わる（＋の後に×を通ると大きく増える）。配置はステージごとに変える
3. ゲートを撃って育てる
   * 弾がゲートに当たると数字が上がる（例：−20 → −19 … → +5）。上限を設ける
   * 撃つ方向と進む方向が同じなので、「ゲートを育てるか、敵を撃つか」の判断が生まれる
4. 変異の繭
   * コース上に耐久値（例：40）が表示された繭があり、近づくまでに撃ち壊すと群れ全体が変異する。壊しきれなければ素通りになる
   * 武器枠は1つ（アギトアリ／ヒアリ／サシハリアリ／自爆アリ）。同じ種類を取るとLv+1（最大3）、別の種類を取ると持ち替えになりLv1から
   * 防具枠は1つ（甲殻装甲）。Lvが上がるほど、攻撃を受けたときに減る数が少なくなる
   * 武器の性能：アギトアリ＝近接で敵を弾き飛ばす／ヒアリ＝毒弾で継続ダメージ／サシハリアリ＝高威力の単発でボスに強い／自爆アリ＝突撃して範囲爆発するが、使うたびに自軍が減る
5. 敵
   * 敵の群れ：ぶつかると1対1で相殺して消える
   * 射撃してくる敵、行く手をふさぐ障害物（石、水たまり）
6. 攻城（後半）
   * 画面下の自分の巣から、指で狙った方向へアリを連続で送り出す。送れる数は前半で集めた数
   * 途中に動くゲートがあり、通ると数が増える。敵の巣の耐久を0にすればステージクリア
7. ボス（各エリアの最後）
   * エリア1 庭：オオカマキリ（鎌で群れの一部を刈り取る）
   * エリア2 森：ジョロウグモ（糸を張って群れの動きを遅くする）
   * エリア3 最終：オオスズメバチ（空から急降下。最後に巨大な女王バチ）
   * ボスもBlender→ドット絵で作り、攻撃の動きのアニメーションを付ける。かっこよさを優先し、暗い色調に光る目と模様で描く

完了の定義：エリア1〜3とボスを、最初から最後まで通しで遊べる。かすり取り、ゲートの育成、変異の取得と持ち替え、攻城がすべて動く。

## 5. フェーズ3：長く遊べる仕組み

1. ランの構成
   * 1ラン＝3エリア×5ステージ（各エリアの5つ目がボス）。1ラン約15分
   * 群れが0匹になったらラン終了。結果画面に「あと○匹でクリアだった」を大きく表示する
2. 法則カード
   * ステージの合間に3枚から1枚を選ぶ。効果はそのランの間だけ続く
   * 最初に12枚以上用意する。例：×ゲートの効果+1／10匹ごとに弾+1／−ゲートを1回だけ無効にする／ゲートの育ちが2倍速／繭の耐久−30%／自爆アリの爆発範囲+50%
   * 組み合わせると強くなる（シナジーがある）カードを意識して作る
3. 永続強化「女王の部屋」
   * ランで倒した敵から「蜜」を得て、ランの外で強化に使う
   * 強化の例：最初の群れの数／弾の威力／繭を壊す速さ／カードの選択肢を4枚に増やす
   * 新しい法則カードの解放もここで行う
4. 難易度
   * 1回クリアすると「侵攻度」を1段上げられる。上げるほど敵が強く、蜜が多くもらえる。最大10段
5. 今日のコース
   * 日付で決まるコースを、全員が同じ配置・同じカード候補で遊ぶ
   * その日の最高記録を保存し、Xシェアの文面に「今日のコース」の記録を入れる

完了の定義：初回プレイからクリアまで約15分、侵攻度と永続強化を含めて合計30分〜1時間遊べる。今日のコースが日付で変わる。

## 6. 手触りと音（フェーズ2・3の全体に適用）

* 数字は一気に変えず、カウンターが回るように増減させる。数が増えるほど効果音の音程を上げる
* ×ゲートを通る瞬間に、約0.2秒のスローモーションと光を入れる
* 群れ同士が相殺すると、消えるアリが粒になって飛び散る。画面の揺れは控えめにし、大きな爆発とボスの攻撃のときだけ揺らす
* ゲートの数字は大きく太く。良い効果は青、悪い効果は赤
* 変異の瞬間は群れ全体に光が走り、見た目が一斉に変わる
* 指を離しても群れは止まらず、その位置のまま前進を続ける
* 効果音：ゲート通過、数の増加、射撃、繭が割れる、変異、相殺、ボス撃破、クリア、ゲームオーバー

## 7. フェーズ4：公開と動画用モード

1. 公開
   * 新しいリポジトリ「army-ants」でGitHub Pagesを有効にし、https://tanukibox.github.io/army-ants/ で遊べるようにする
   * tanukibox.github.io のトップページに、このゲームへのリンクを追加する
   * 公開の手順は、歩夢が1つずつ実行できるように説明する
2. 動画用モード（X投稿のプレイ動画用）
   * 設定画面の奥に隠しスイッチを置き、オンにすると次のことができる：UI（ボタン類）を隠す／好きなエリア・ステージから始める／最初の匹数を自由に決める（例：1万匹）／好きな変異とLvで始める
   * 9:16の縦画面で、画面録画に向いた表示にする
   * プレイ動画の作り方（スマホの画面録画か、自動で録画する仕組みか）は、歩夢と相談して決める
3. 最終チェック
   * iPhoneとAndroidのブラウザ、PCのChromeで、最初から最後まで遊べることを確認する
   * 日英の表示、セーブ、Xシェア、今日のコースを確認する

完了の定義：公開URLをスマホで開いて遊べる。動画用モードで、1万匹の群れが変異した場面を録画できる。
